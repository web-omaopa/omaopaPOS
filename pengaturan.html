Tambah Produk

Ini harga dasar untuk penjualan Offline, dan jadi harga default untuk mode lain kalau tidak diisi harga khusus di bawah.
Kosongkan untuk pakai default "pcs". Untuk topping biasanya "gram".
Atau upload langsung dari komputer:
Isi harga = produk ini dijual di mode tsb dengan harga itu. Kosongkan = produk TIDAK dijual di mode tsb (tidak otomatis ikut Harga Offline).

Tambah Outlet

Nama ini jadi ID permanen, tidak bisa diganti nanti.
Buka Google Maps, cari lokasi, klik "Bagikan" untuk salin link.

Tambah User Baru

Membuat akun login (Authentication) sekaligus profil (Firestore).

Edit User

Untuk ganti password, lakukan lewat Firebase Console.

Kelola Mode Penjualan

Tambah channel baru, atau klik × untuk hapus yang sudah tidak dipakai.
ATAU
Klik "+" di daftar untuk langsung menambahkan mode itu tanpa ketik manual.

Kelola Kategori Produk

Tambah kategori baru, atau klik × untuk hapus yang sudah tidak dipakai.

Tambah Promo

Kosongkan kedua tanggal untuk promo tanpa batas waktu (matikan manual lewat Status kalau perlu).
Centang kosong = berlaku di semua outlet.
Centang kosong = berlaku di semua mode (termasuk Offline).
